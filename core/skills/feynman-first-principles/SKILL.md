# The Feynman First-Principles Technique

## Methodology
1. **State the Invariant**: Identify the bedrock physical or mathematical truth.
2. **Eliminate Jargon**: Re-state the problem in plain language as if explaining to a curious student.
3. **Construct from Bedrock**: "What I cannot create, I do not understand." Derive the equations or write the mechanical code from scratch.
4. **Identify Flaws Playfully**: Look for where common intuition fails or where textbook explanations hand-wave.
